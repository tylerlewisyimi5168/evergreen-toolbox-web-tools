## What Is EvergreenToolbox?

EvergreenToolbox brings a range of practical browser utilities together in a static website. Every tool runs on the user's device, while the complete site can be published through GitHub Pages without requiring a server-side application or database.

The project supports both Korean and English through its multilingual, browser-only design. Its lightweight interface can serve general users, students, and anyone looking for convenient calculators, generators, printable paper templates, or practice resources.

## Frequently Asked Questions

**Does EvergreenToolbox need a backend?**  
No. The tools are intended to run in the browser and do not depend on a server or database.

**How do I release changes?**  
Change the static project files, commit or upload the updates to the repository, and redeploy through GitHub Pages.

**How is multilingual behavior defined?**  
Language information is represented in the static site structure through page metadata and language-aware navigation links.

**What should I check if a tool fails to load?**  
Inspect the browser console, verify that all required static assets are available, and confirm that the page is being served from the intended GitHub Pages location.

**Are the tools and templates customizable?**  
Yes. Edit the corresponding static HTML, script, or asset files and publish the site again after making the desired changes.
